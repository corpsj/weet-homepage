웹에 접속할때는 localhost를 사용하지 않고 we-et.com 도메인을 사용해 진짜 빌드후 표시되는 화면을 체크해야합니다.
그러려면 브랜치를 푸쉬 후 웹사이트가 vercel에서 빌드되기를 기다려야 합니다.
특이사항은 브랜치로 푸시하면 vercel에서 자동으로 배포되지 않습니다. 자동으로 배포되도록 vercel에 설정해주세요.
vercel은 크롬에 탭을 열어뒀습니다.

만약 자동 배포가 안된다면 웹제어를 통해서 https://vercel.com/weets-projects-6c7745e8/weet-homepage/deployments 페이지에서 브랜치가 푸시되어 대기중인것을 확인하고 해당 커밋의 우측의 점세개 버튼을 클릭해 Promote 를 선택해서 배포해야 합니다.
